常见问题

扫码没有反应 / 打不开相机？

请在 iOS「设置 → 二维码&条形码 → 相机」中允许相机权限。也可改用“相册”或“扫描网络图片”识别图片中的码。

支持哪些条形码？

扫描支持二维码及常见一维码（EAN、UPC、Code 128、Code 39、Code 93、ITF、Codabar 等）；生成支持 Code 128 与 Code 39。

生成的二维码能自定义吗？

可以。生成二维码时可设置颜色、容错级别，并嵌入 Logo；生成后可保存到相册或分享。

怎么切换语言或深色模式？

进入「二维码/条形码」页右上角「设置」，可切换语言（中/英/日/韩/泰）与主题（跟随系统/浅色/深色）。

历史记录在哪里？会上传吗？

在「设置」旁的历史图标，或首页“历史记录”。所有记录仅保存在本机，不会上传，可随时删除或导出。

会收集我的隐私吗？

不会。无账号、无广告、无第三方统计，不收集任何个人信息。详见隐私政策。

FAQ

Scanning doesn't work / camera won't open?

Allow camera access in iOS Settings → QR & Barcode → Camera. You can also use “Album” or “Scan from image URL” to detect a code in an image.

Which barcodes are supported?

Scanning supports QR plus common 1D barcodes (EAN, UPC, Code 128, Code 39, Code 93, ITF, Codabar, etc.). Generation supports Code 128 and Code 39.

Can I customize the QR code?

Yes. Set color and error-correction level, and embed a logo. You can then save to Photos or share.

How do I change language or dark mode?

Open “Settings” (top-right on the QR/Barcode tab) to switch language (EN/中文/日/한/ไทย) and theme (System/Light/Dark).

Where is my history? Is it uploaded?

Via the history icon next to Settings, or “History” on the home screen. All records stay on your device, are never uploaded, and can be deleted or exported anytime.

Do you collect my data?

No. No account, no ads, no third-party analytics, no personal data collected. See the Privacy Policy.
